# mind-oasis-sandbox

Founder test build of the MIND OASIS web app, served by GitHub Pages.

This repository holds **only the built web files** (`index.html`, `main.dart.js`, the Flutter engine, fonts and assets). Source code, prompts, research and project state live in the private repository and must never be copied here. The `build-only guard` check fails if anything else is pushed.

Deploy: copy the contents of the private repo's `web-preview-build` branch output (with base href `/mind-oasis-sandbox/`) over these files, keep `README.md`, `.nojekyll` and `.github/`, commit, push.
